# Dashboard
## Overview

This folder contains the Power BI dashboard created as part of the Nike Sales Data Analysis Project. 
The dashboard presents key business insights derived from SQL analysis in an interactive and visually intuitive format.
Dashboard Features

## The dashboard includes:

Key performance indicators (KPIs) for sales, revenue, and profit

Product-wise and category-wise performance analysis

Regional and sales channel comparisons

Discount impact on revenue and profitability

Interactive filters and slicers for dynamic exploration

## Data Source

Cleaned dataset generated using Python (Pandas)

Business insights derived using PostgreSQL

Final data model imported into Power BI

## Usage Notes

Open the .pbix file using Microsoft Power BI Desktop

Ensure the dataset path is updated if prompted

Designed for both technical and non-technical stakeholders

## Purpose

The dashboard serves as a visual storytelling tool to:

Translate analytical findings into business insights

Support data-driven decision-making

Demonstrate practical Power BI skills

## Note

This dashboard is created for learning and portfolio purposes and reflects a real-world analytics workflow.
