# Nike Sales Data Analysis Project
## Project Overview

This project is an end-to-end Data Analysis workflow built using a Nike sales dataset sourced from Kaggle. The objective of the project is to understand sales performance, uncover business insights, and present findings through clear visualizations and reporting.

The project covers the complete data pipeline — from raw data exploration to dashboard creation — using industry-relevant tools.

### Dataset

Source: Kaggle

Domain: Retail / Sales Analytics

Data Type: CSV (structured data)

The dataset contains information related to Nike product sales, including product details, sales metrics, discounts, revenue, profit, regions, and sales channels.

### Tools & Technologies Used

Excel – Initial data exploration and understanding

Python (Pandas) – Data cleaning and preprocessing

Matplotlib & Seaborn – Exploratory data analysis and visualization

PostgreSQL – Business analysis using SQL queries

Power BI – Interactive dashboard creation

GitHub – Version control and project documentation

Project Workflow

### Data Understanding

Explored the raw dataset using Excel

Identified missing values, inconsistencies, and key columns

### Data Cleaning & Preprocessing

Cleaned and transformed data using Pandas

Handled missing values, corrected data types, and removed inconsistencies

Performed exploratory visual analysis using Matplotlib and Seaborn

### Business Analysis (SQL)

Imported cleaned data into PostgreSQL

Wrote SQL queries to analyze:

Sales performance

Product-wise trends

Revenue and profit distribution

Regional and channel-based insights

### Dashboard Development

Built an interactive Power BI dashboard

Visualized KPIs, trends, and business metrics

Focused on clarity and usability for stakeholders

### Reporting

Created a detailed project report

Prepared a presentation summarizing insights and outcomes

### Key Insights

Identification of top-performing products and categories

Revenue and profit trends across regions and sales channels

Impact of discounts on sales and profitability

Customer and product-level performance patterns
