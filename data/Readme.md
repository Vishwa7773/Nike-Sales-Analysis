# Data Folder
## Overview

This folder contains the datasets used in the Nike Sales Data Analysis Project. The data in this directory serves as the foundation for all data cleaning, analysis, and visualization tasks performed in the project.

Files Description
File Name	Description
Nike_Sales_Uncleaned.csv	Raw dataset sourced from Kaggle. This file contains the original data before any cleaning or transformation.
Data Usage

The raw dataset is used for initial exploration and understanding.

Data cleaning and preprocessing are performed using Python (Pandas).

Cleaned datasets (if generated) are used for SQL analysis and Power BI dashboards.

Important Notes

The raw data file should not be modified directly.

Any transformed or cleaned versions of the data should be saved as separate files (e.g., Nike_Sales_Cleaned.csv).

This ensures data reproducibility and traceability throughout the analysis pipeline.

Data Source

* Kaggle – Public dataset used for educational and analytical purposes.
