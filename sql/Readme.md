# SQL Analysis
## Overview

This folder contains all SQL scripts used for business analysis in the Nike Sales Data Analysis Project. The queries were written and executed using PostgreSQL to extract insights from the cleaned dataset.

### Files Description
#### File Name	Description
Nike_Analysis.sql	Contains SQL queries used for exploratory analysis, aggregations, and business insights such as sales trends, revenue, profit, and product performance.
Analysis Scope

### The SQL queries in this folder focus on:

Sales and revenue analysis

Product and category performance

Regional and channel-based insights

Discount and profitability analysis

Aggregations using GROUP BY, ORDER BY, and filtering with WHERE

Database Used

PostgreSQL

The cleaned dataset was imported into PostgreSQL before executing the analysis queries.

Usage Notes

Queries are written for analysis and learning purposes

Each query is structured to be readable and modular

The scripts can be executed directly in pgAdmin or any PostgreSQL-compatible client

Learning Outcome

Working with SQL in this project improved understanding of:

Translating business questions into SQL queries

Using aggregations for analytical insights

Integrating SQL results into dashboards and reports
