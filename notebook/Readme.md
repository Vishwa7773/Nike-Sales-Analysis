# Notebooks
## Overview

This folder contains Jupyter notebooks used for data cleaning, preprocessing, and exploratory data analysis (EDA) in the Nike Sales Data Analysis Project. 
The notebooks document the step-by-step process followed to transform raw data into an analysis-ready format.
## Tools & Libraries Used

*Python

*Pandas – Data manipulation and cleaning

*Matplotlib – Basic data visualization

*Seaborn – Statistical and exploratory plots

## Notebook Scope

The notebooks in this folder include:

Initial data exploration

Handling missing and inconsistent values

Feature understanding and basic transformations

Visual exploration to identify trends and anomalies

## Usage Notes

Notebooks are intended to be run sequentially

The raw dataset is read from the data/ directory

Outputs from these notebooks are used for SQL analysis and dashboard creation

## Learning Outcome

Working with these notebooks helped strengthen:

Practical data cleaning techniques

Exploratory data analysis skills

Visualization for insight discovery

Preparing datasets for downstream analytics tools

## Note

These notebooks are created for learning and portfolio purposes and focus on clarity and reproducibility.
